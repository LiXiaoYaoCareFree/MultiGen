# 统一评估数据集原型构建报告

## 一、数据采集概况

本原型数据集覆盖了4个学科大类、6个子学科，共13篇代表性学术论文，旨在展示统一评估数据集的构建流程和质量控制机制。论文来源均为arXiv公开预印本，通过各学科的针对性检索策略收集。
