# AI科研工具横向对比 — 综合评估报告

## 执行概要

本报告展示了在统一评估数据集上运行三种典型AI科研论文生成工具（GPT Researcher、PaperQA2、SciMON）的完整流程和评估结果。整个流程包括：统一接口封装、数据集任务分配、论文生成、多维度评估（自动化指标+AI评审器）、横向对比分析和评审器间一致性分析。

---

## 一、参与工具

| 工具 | 版本 | 基础模型 | 架构特点 | 核心优势 | 核心劣势 |
|------|------|----------|----------|----------|----------|
| GPT Researcher | v2.1.0 | GPT-4o | RAG多Agent | 引用准确、文献全面、结构规范 | 创新性较弱、速度较慢 |
| PaperQA2 | v3.2.0 | Claude 3.5 Sonnet + RAG | Language Agent | 事实准确、跨文献综合强 | 成本高、偶有过度引用 |
| SciMON | v1.0.0 | LLaMA-3 70B + KG | Inspiration Retrieval | 创新性强、超凡假设 | 事实一致性低、过度推断 |
