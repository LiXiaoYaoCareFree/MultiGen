# 公开数据集

## 资源分类说明

- **结构化数据集**：包含结构化数据文件（JSON、CSV等），可直接下载使用，通常包含评审意见、接受/拒绝标签等。
- **平台/服务**：提供数据访问的在线平台或API，可能包含动态数据。
- **会议/期刊资源**：官方公布的接受论文列表或论文集，通常为HTML页面或PDF。
- **开放获取数据库**：大规模开放获取论文库，包含全文但可能缺少评审信息。
