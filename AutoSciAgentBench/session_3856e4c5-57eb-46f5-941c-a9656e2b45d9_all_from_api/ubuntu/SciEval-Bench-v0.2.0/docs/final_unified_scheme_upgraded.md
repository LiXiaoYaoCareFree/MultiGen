# 统一AI自动科研评估数据集构建与评估方案（升级版）

## 一、引言

近年来，以大语言模型为代表的人工智能技术在科学研究中的角色正从辅助工具向"自动研究者"快速演进。从AI-Scientist首次展示全自动科学发现的可能性，到AI-Researcher提出Scientist-Bench标准化基准，再到Research Arena揭示通用CLI Agent的科研能力边界，AI自动科研已成为学术界和产业界共同关注的焦点。
