# 统一AI自动科研评估数据集 — 最终规范（v1.0）

## 一、数据集标识与版本

- **名称：** SciEval-Bench（Scientific Evaluation Benchmark）
- **版本：** 1.0.0
- **发布日期：** 目标第一期发布
- **维护团队：** 开放社区维护，采用语义化版本控制
- **许可证：** CC BY 4.0（数据标注） + MIT（构建代码）

## 二、目标规模与分布

### 2.1 总体规模

| 指标 | 第一期目标 | 第二期目标 | 最终目标 |
|------|-----------|-----------|----------|
| 学科大类 | 6 | 6 | 6 |
| 学科门类 | 12 | 20 | 30 |
| 子学科 | 32 | 60 | 100+ |
| 任务实例总数 | 1200 | 3000 | 5000+ |
| Code-Aware实例 | 360 | 1200 | 2000+ |
| 编造检测清单条目 | 1800+ | 6000+ | 10000+ |

### 2.2 学科分布（第一期）

每个学科大类的实例数量按实际论文产出量和领域多样性进行加权分配。

**形式科学——480条（40%）。** 这是AI科研工具当前表现最成熟的领域，也是Research Aren
