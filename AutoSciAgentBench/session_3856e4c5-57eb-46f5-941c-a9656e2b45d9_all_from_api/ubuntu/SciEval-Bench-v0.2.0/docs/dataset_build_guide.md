# 统一AI科研评估数据集 — 用户构建指南

## 这个数据集包含什么

在你动手构建之前，先了解这套数据集最终产出的内容。每一条数据集实例围绕一篇真实论文构建，包含以下核心数据元素：

**学科标签。** 四层级学科路径。例如：形式科学 → 计算机科学 → 自然语言处理 → 文本生成。跨学科论文会有多个标签。

**任务定义。** 明确的任务类型（六选一：文献综述生成、研究提案生成、实验方案设计、完整论文生成、论文扩展改写、同行评审生成）和难度级别（三级：引导式执行Level-1、半自主探索Level-2、全自主研究Level-3）。

**输入材料。** 根据任务类型和难度级别，从目标论文中提取并经匿名化处理的研究材料——例如Level-1完整论文生成任务会提供研究假设描述和结构化实验数据，Level-2则仅提供研究主题和参考文献列表。

**参考输出。** 原始论文的结构化
